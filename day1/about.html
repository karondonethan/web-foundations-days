About QuickNotes

QuickNotes is a simple web app for capturing short notes, ideas and reminders the moment they come to mind. It is built for students and busy people who want to jot things down without any clutter.

How to use QuickNotes

  1. Open QuickNotes and click the note box at the top of the page.
  2. Type your note, giving it a short title if you like.
  3. Click Save to store the note in your list.
  4. Select any saved note to edit it, or delete it when you are done.

Features

  • Quick note capture with one click
  • Clean, distraction-free layout
  • Edit and delete notes at any time
  • Keyboard shortcuts for faster work

Keyboard shortcuts

Shortcut Action
Ctrl + N Create a new note
Ctrl + S Save the current note
Ctrl + D Delete the selected note
